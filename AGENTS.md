# Agent notes

Repo-specific guidance for AI coding agents working here, regardless of which tool
you are.

## Agent workflows

Reusable, repo-specific workflows for AI coding agents live under `.claude/skills/`
(one directory per workflow, each with a `SKILL.md` describing when and how to use
it). Currently:

- `generate-pr` — drafts a PR from the real diff using this repo's PR template.
- `preflight` — runs the full local CI-equivalent check suite against the current
  branch before opening or updating a PR.

## Commit and PR authorship

Commits and PRs in this repo should read as the human contributor's own. When an AI
coding assistant (Claude, Codex, Copilot, or any other tool) does the work, do not add
a `Co-Authored-By: <assistant>` trailer, a "Generated by ..." notice, or any other
attribution to the assistant — in commit messages, PR titles, or PR descriptions.
